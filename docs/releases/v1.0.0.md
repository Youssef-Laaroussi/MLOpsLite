# MLite v1.0.0 GA Release Notes

**Release Date:** September 2026  
**Tag:** `v1.0.0`  
**Status:** General Availability (GA) & Enterprise Production Ready

---

## 1. Welcome to MLite 1.0

MLite 1.0 is the culmination of our commitment to delivering a **fast, lightweight, and self-hosted MLOps platform** that does not compromise on production rigor, security, or observability.

With this release:
- **API Freeze**: All public REST API endpoints (`/api/v1/*`) and CLI interfaces are declared stable and frozen under Semantic Versioning 2.0.
- **Production Ready**: Security audited, container-hardened, and validated with end-to-end integration and lifecycle testing.
- **Enterprise Self-Hosting**: Comprehensive reference architectures for high-availability PostgreSQL, MinIO distributed object storage, and reverse-proxy TLS termination.

## 3. Backwards Compatibility & Stability Guarantee

Starting with version `1.0.0`:
1. **Public API Contract**: No breaking changes will be introduced to `/api/v1/` routes without a deprecation period spanning at least one minor release cycle.
2. **Database Migrations**: All future database updates will include forward and backward migration scripts via Alembic.
3. **CLI Arguments**: Existing CLI flags and commands will remain backwards compatible across all `1.x.x` releases.

---

## 4. Upgrade Path from v0.1.0

If upgrading from the `v0.1.0` MVP preview:

1. **Pull Latest Code and Images**:
   ```bash
   git pull origin main
   docker compose pull
   ```

2. **Apply Database Migrations**:
   ```bash
   alembic upgrade head
   ```

3. **Run Pre-Flight Smoke Test**:
   ```bash
   python scripts/release_smoke_test.py
   ```

4. **Restart Services**:
   ```bash
   docker compose up -d
   ```
