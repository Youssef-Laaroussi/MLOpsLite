# MLite v0.1.0 Release Notes

**Release Date:** September 2026  
**Tag:** `v0.1.0`  
**Status:** MVP Community Preview

---

## 1. Executive Summary

We are proud to announce the first official community preview release of **MLite (v0.1.0)** — the lightweight, self-hosted MLOps platform engineered for teams requiring production-grade machine learning lifecycle governance without the operational complexity or cost of multi-cluster enterprise suites.

MLite v0.1.0 provides a single cohesive interface across CLI, REST API, and containerized serving to take machine learning models from experiment tracking directly to resilient production serving.

---

## 2. Key Highlights & Features

### 🗄 1. Data Versioning & Registry
- **Integrity**: Automatic SHA-256 content-addressable hashing.
- **Storage Flexibility**: Pluggable storage providers supporting local filesystem and S3/MinIO backends.
- **CLI & REST Integration**: `mlite data register`, `mlite data list`, and `mlite data get`.

### 🔬 2. Experiment Tracking (MLflow Integration)
- Native integration with MLflow tracking servers.
- Automated hyperparameter, metric, and artifact logging.
- Support for run tags, experiments, and comparison views.

### 📦 3. Model Registry
- Semantic model versioning with lifecycle states (`staging`, `production`, `archived`).
- Automated artifact upload and download via MinIO blob storage.
- Strict input/output schema validation and metadata tracking.

### 🚀 4. Containerized Model Serving
- Dockerized isolated runtime containers for model execution.
- Configurable resource limits (CPU, memory).
- Automated health check probes (`/health`) and dynamic port binding.
- Sub-50ms inference latency overhead.

### 📊 5. Drift Detection & Quality Monitoring
- Powered by **Evidently AI** statistical engine.
- Kolmogorov-Smirnov (KS) tests for continuous numerical distributions.
- Chi-Square / Wasserstein distance for categorical features.
- Ingestion of delayed ground-truth feedback for live RMSE/MAE tracking.

### 🔄 6. Reliability & Auto-Rollback Engine
- Manual one-command CLI rollback: `mlite rollback <deployment> --to <version>`.
- Automated rule-based rollback policies triggered on:
  - Error rate spikes (> 5% in rolling window)
  - Severe feature drift (KS $p < 0.05$)
  - Health check timeouts
- Zero-downtime traffic switching with pre-flight health validation.

### 🛡 7. Security, RBAC & Audit Trails
- **Authentication**: JWT bearer tokens and secure API key authentication.
- **RBAC**: Hierarchical role-based access control (`viewer`, `operator`, `admin`).
- **Audit Logging**: Write-only immutable audit trail recording all administrative, deployment, and rollback actions.

## 3. Installation & Quickstart

### Using pip
```bash
pip install mlite
mlite init my-ml-project
```

### Using Docker Compose
```bash
git clone https://github.com/Youssef-Laaroussi/MLOpsLite.git
cd MLOpsLite
docker compose up -d
```

Access the MLite ecosystem:
- **API Documentation**: [http://localhost:8000/docs](http://localhost:8000/docs)
- **MLflow Tracking UI**: [http://localhost:5000](http://localhost:5000)
- **MinIO Storage Console**: [http://localhost:9001](http://localhost:9001)

---

## 4. Known Limitations in v0.1.0

- Distributed Kubernetes serving is scheduled for the v1.x roadmap; v0.1.0 uses Docker engine host orchestration.
- Batch inference scheduling requires external cron or orchestration tools (Airflow/Prefect).
- Database migrations are managed via Alembic; ensure `mlite.db` or PostgreSQL is backed up before applying major schema updates.
